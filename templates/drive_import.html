Import from Google Drive

Save Drive folders and workbook links for everyone using this CRM server.

Paste a Google Drive folder, Google Sheets or Drive Excel link. Folders open the source collection; select an individual workbook for import. Saving a link does not import its rows or change its Google sharing permissions. Use Preview / import for a one-time import, or Connect for sync for ongoing Leads & Queries updates. Files can stay private; each viewer needs Google access to open them.

Shared workbookImport sectionActions

Fetching the latest private Drive file requires Google server credentials and Viewer permission. Alternatively, attach its downloaded Excel copy: the CRM saves that copy in the database for everyone. Import saved copy uses that dated snapshot, without fetching newer Drive edits. Imports retain the existing mapping and backup behavior. Links and workbook copies remain when dashboard records are reset; removing a link does not remove imported records.
