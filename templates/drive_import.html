Import from Google Drive

Save workbook links for everyone using this CRM server.

Paste a Google Sheets or Drive Excel link. Saving a link does not import its rows or change its Google sharing permissions. Use Preview / import for a one-time import, or Connect for sync for ongoing Leads & Queries updates. Files can stay private; each viewer needs Google access to open them.

Shared workbookImport sectionActions

Private imports require Google server credentials with Drive read access and Viewer permission on the file. Otherwise open the link, download Excel from Drive, and use Import Excel. Imports retain the existing preview/confirmation and backup behavior. Links remain saved when dashboard records are reset; removing a link does not remove imported records.
