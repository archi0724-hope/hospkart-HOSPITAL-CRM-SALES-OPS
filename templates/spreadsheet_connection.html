Connect Spreadsheet

Connect separate Leads and Queries tabs, or a single Google Form response worksheet. Headers must be in row 1. This connection reads from the sheet only; source rows removed from the sheet stay in the CRM.

An administrator must configure Google access on the server and share the sheet with that service account as Viewer. Keep the sheet private.

Only the administrator can save or change this connection. Team members can open the saved form. Manual sync and setup changes require admin sign-in. Sign in using Admin sign-in to manage the connection.

Automatic sync runs while the server is running with its scheduler enabled. The open dashboard checks for saved changes every 30 seconds. Use YYYY-MM-DD for dates and Plain text for IDs and phone numbers.

Each response creates a lead. Product Inquiry, Customer Query, Existing Customer Query, Query, Service Inquiry and Service Request also create a linked query; New Sales Lead and New Lead create only a lead. Other submission types are flagged for review. A unique immutable Response ID is preferred. Otherwise, the submission timestamp identifies the record: keep it unchanged and unique. Duplicate IDs/timestamps are rejected. Names, phone numbers and row positions are never used to identify a response. Separate responses from the same customer remain separate leads.

* Required mapping. Unmapped CRM fields are kept. Blank cells in mapped columns clear those values. IDs are case-sensitive; names and row positions are never used for matching. Matching IDs also update the displayed record in this browser.

Import preview

Up to 10 valid rows per tab are shown. Import applies the reviewed snapshot; invalid rows are rejected and existing saved records are kept. The preview expires after 15 minutes. Review ID collisions before continuing.
